# Security

Found a vulnerability in tcf.monster? Thank you — please tell me first.

- **Telegram**: [@tcfmonsteradmin](https://t.me/tcfmonsteradmin)
- Say what you found and how to reproduce it. A short note is fine.
- Please do not access, change or delete other people's data.

I answer within a few days and fix what is real as fast as I can. There is no bug bounty, but I am happy to thank
you by name if you wish.
